## Design decision and interfaces

Use an automatic post-translation source-image layout pass. The existing ordinary layout proposal schema already expresses paragraph roles, safe target phrase emphasis, spacing, panels and two-/three-column physical bands. The saved-layout renderer already preserves editable paragraph/run content. Reuse that machinery before inventing a second visual translation transport.

A new bilingual visual protocol would require new source-readiness semantics, glossary/literal protection, response parsing, retries, checkpoint identity and source-geometry qualifications. A same-response source transcription is not independent proof of translated fidelity. Keep that alternative deferred unless concrete real acceptance demonstrates that the existing translated paragraph representation cannot support the requested structure.

The automatic pass must not retranslate, rewrite, reorder or delete target text. It cannot fix a target paragraph that improperly combines unrelated physical regions, or mistranslated logical order.
